# 雅思冲刺簿

雅思 6.0 → 7.5 的备考进度应用：打卡计时、模考走势、写作批改、间隔复习卡、资料库。

**网址：https://zzzhida.github.io/ielts/**

- **离线可用**：数据存在设备本地，断网照常记录。
- **多设备同步（可选）**：数据存进你自己 GitHub 账号里的一个私密 Gist，不经过第三方。
- **装到主屏幕**：安卓和 iPad 都能像 App 一样打开。

## 第一次使用

### 1. 打开 GitHub Pages（只做一次）

进入仓库的 **Settings → Pages**，在 Build and deployment 里设置：
- Source 选 **Deploy from a branch**
- Branch 选 `main`，文件夹选 `/ (root)`

点 Save，等 1–2 分钟，上面的网址就能打开了。

### 2. 装到设备上

- **安卓（Chrome）**：打开网址，点右上角 ⋮，选「安装应用」或「添加到主屏幕」。
- **iPad（Safari）**：打开网址，点分享按钮，选「添加到主屏幕」。

第一次打开需要联网，之后断网也能用。

### 3. 开启同步（需要在手机和 iPad 之间同步时再做）

1. 浏览器打开 https://github.com/settings/tokens/new （路径：Settings → Developer settings → Personal access tokens → Tokens (classic)）
2. Note 填「雅思冲刺簿」，Expiration 选 1 年，权限**只勾 `gist`**，然后生成并复制 `ghp_` 开头的令牌。
3. 应用右上角菜单 → **云同步**，粘贴令牌，点「保存并同步」。
4. 另一台设备做同样的第 3 步，填**同一个**令牌。

之后改动会在几秒内自动同步。没网时先存在本机，联网后自动补传。同一条记录在两台设备都改过时，以后改的那份为准。令牌只保存在当前设备上；只勾了 gist 权限，即使泄露，别人也动不了你的代码仓库。

## 功能

| 页面 | 能做什么 |
|---|---|
| 今天 | 考试倒计时、当前阶段和每日目标；点一下 +15 分钟，或者用计时器边学边计；本阶段任务清单；连续打卡和 8 周热力图；连续 2 天没学会出提醒 |
| 打卡 | 补录某一天，写备注；每周时长柱状图，带本阶段的每周目标线 |
| 成绩 | 听力和阅读填正确题数，自动换算分数，总分按官方规则取整；分数走势图；作文存档，「复制去批改」可以一键把题目、原文和评分要求发给老师或 AI |
| 复习 | 错题卡、表达卡、方法卡，按 1/3/7/14/30/60 天间隔复习 |
| 资料 | 内置 37 条资料（官方模考、评分标准、澳门考点报名、听说读写资源、书目、方法），可以搜索、增删 |

菜单里还有：考试与目标、云同步、每日提醒（生成日历事件）、复制进度摘要、导出和导入备份。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用 |
| `seed.js` | 内置的阶段计划、任务、资料和复习卡 |
| `sw.js` | 离线缓存：联网时自动取最新版，没网时用缓存 |
| `manifest.webmanifest`、`*.png` | 主屏幕图标和名称 |

## 修改内容

- **改资料或复习卡**：编辑 `seed.js`，把 `SEED_VERSION` 加 1 后提交。已安装的设备下次联网打开时会补上新增的条目，你改过或删过的条目不受影响。
- **改应用本身**：直接修改并提交 `index.html`。不用改缓存版本号，设备联网时会自动取到新版。

## 备份

菜单 → 导出备份，会下载一个 JSON 文件。导入时会和现有数据合并，不会覆盖更新的记录。
